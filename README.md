# Лабораторная работа №1 Консольный набор утилит

### Установка

Для работы программы необходим Python версии 3.12 или выше.

Клонировать репозиторий:

```bash
git clone https://github.com/ShelMakar/lab1.git
cd lab1
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

```bash
pip install -r requirements.txt
```

Для запуска проверок качества кода также необходимо установить `pre-commit`:

```bash
pip install pre-commit
pre-commit install
```

## Конвектер 

принимает на вход только единицы измерения одинаковой группы (длина, время и тд)

Допустимые значения

* `mm` `sm` `m` `km` - для длины
*  `f` `k` `c` - для температуры
* `s` `min` `h` - для времени
* `g` `kg` - для массы

Чтобы конвертировать выражение в терминале нужно написать программу
```bash
python -m toolkit convert VALUE --from UNIT --to UNIT
```
Где
* `value` - значение
*  `UNIT` - единицы измеренеия

## Калькулятор

### Использование

Калькулятор принимает арифметическое выражение в виде строки и возвращает результат его вычисления.

Поддерживаются следующие операторы:
* `-` `+` `*` `/` `//` `%`

Все операторы работают как в Python

Также поддерживаются круглые скобки:

```text
(2 + 3) * 4
```

и унарные операторы `+` и `-`:

```text
-5
+5
2 * -3
```

---

## Обработка выражения

Перед вычислением выражение проходит несколько этапов проверки.

### 1. Проверка символов

Из выражения удаляются пробелы и проверяется наличие недопустимых символов.

Допустимыми являются:

* цифры;
* точка;
* `+`;
* `-`;
* `*`;
* `/`;
* `(`;
* `)`.

Например:

```text
2 + 3 * 4
```

является корректным выражением, а

```text
2 + a
```

содержит недопустимый символ.

---

### 2. Определение унарных операторов

Операторы `+` и `-` могут быть как бинарными, так и унарными.

Если оператор находится между двумя операндами, он является бинарным:

```text
2 + 3
2 - 3
```

Если `+` или `-` находится в начале выражения, после открывающей скобки или после бинарного оператора, он может рассматриваться как унарный:

```text
-3
+3
2 * -3
(-3)
```

Поддерживаются последовательности унарных операторов:

```text
--3
++3
-+3
+-3
```

В таком случае операторы последовательно применяются к следующему операнду.

---

### 3. Проверка корректности выражения

После определения операторов проверяется структура выражения.

Проверяется:

* наличие операндов у бинарных операторов;
* корректное расположение унарных операторов;
* правильное расположение скобок;
* отсутствие двух бинарных операторов подряд;
* отсутствие двух операндов подряд;
* отсутствие незакрытых или лишних скобок.

Например, следующие выражения являются некорректными:

```text
2 + * 3
2 * / 3
2 3
(2 + 3
2 + 3)
```

Отдельно запрещается конструкция:

```text
2 * -(-3)
```

Такое выражение считается некорректным, поскольку после бинарного оператора `*` начинается последовательность, в которой унарный оператор непосредственно применяется к выражению в скобках.

## Приоритет операций

При вычислении используется следующий порядок операций:

1. унарные `+` и `-`;
2. умножение и деление;
3. сложение и вычитание.

Скобки имеют наивысший приоритет.

## Тестирование

Для проверки работы калькулятора используются тесты `pytest`.

Запуск всех тестов:

```bash
pytest
```

Запуск с подробным выводом:

```bash
pytest -v
```

Тесты проверяют:

* базовые арифметические операции;
* приоритет операторов;
* работу скобок;
* целые и вещественные числа;
* унарные операторы;
* последовательности `++`, `--`, `+-`, `-+`;
* пустые выражения;
* недопустимые символы;
* некорректные выражения;
* деление на ноль.

## Структура проекта

```text
lab1/
├── src/
│   └── toolkit/
│       ├── __init__.py
│       ├── calculator.py
│       ├── constants.py
│       └── errors.py
```

`calculator.py` содержит основную логику обработки и вычисления выражений.

В каталоге `tests` находятся тесты для проверки корректной и некорректной работы калькулятора.
